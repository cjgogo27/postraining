| 名称 | 本书含义与反例 |
| --- | --- |
| 中训练 | 已有基座的能力或分布适配工作范围；没有全行业统一起止点 |
| DAPT / TAPT | 领域/任务自适应继续预训练；原始DAPT论文主要是掩码语言模型 |
| 回放 | 将通用数据继续混入；不能保证所有旧能力不退化 |
| token预算 | 实际参与监督的目标消费量，包含重复；不等于唯一文档量 |
| 微批次 | 一次前向反向的本地样本；多个微批次可累积成更新 |
| DP / TP / PP / CP | 数据副本/张量切分/层间流水/上下文切分；只有DP直接复制源批次 |
| attention mask | 控制能看谁；不自动决定哪些标签参与loss |
| loss mask | 控制哪些目标被监督；不自动隔离文档注意力 |
| 严格恢复 | 同代码/数据/计划/环境与布局下续接训练状态 |
| 新阶段 | 继承权重，重建优化器与计数；不冒充严格恢复 |
| 长度接口测试 | 验证形状、预算与状态可跑；不等于长依赖能力测试 |
| NLL / PPL | 固定协议下负对数似然及其指数；跨分词器不可直接比 |

默认S32的512评测目标来自固定窗口，窗口可重叠。它们是累计计数，不是512个独立实验单位。两seed是两组小实验，不足以报告总体显著性。

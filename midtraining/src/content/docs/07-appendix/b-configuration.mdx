## 默认教学模型

| 项目 | 实际配置 |
| --- | --- |
| 独立参数 | 23,040；输入嵌入与输出头共享 |
| block | 1层，宽32，4头MHA，FFN128/GELU，LayerNorm |
| 位置与词表 | 学习位置64；字节0–255，EOS256；dropout0 |
| 精度/设备 | CPU FP32，单进程，torch线程1 |
| base | B4/S32，120更新，lr峰值0.003 |
| 三个适配支路 | B4/S32，96更新，各12,288目标，峰值0.001 |
| 优化器 | AdamW，weight decay0.01，梯度裁剪1 |
| 调度 | 4更新warmup后余弦至峰值10% |
| 评测 | 每源固定S32×16或S64×8窗口，512累计目标 |

命令、源配额和参数来源以`midtraining/examples/lab.py`与JSON中的config为准。代码身份按LF规范化后的完整lab源计算，不因Windows换行不同而改变；代码逻辑变化会改变SHA。

严格恢复核对代码SHA、数据身份、完整配置、PyTorch版本、world size与编码契约，并恢复模型、AdamW、随机状态、窗口账本和计数。此实现仅在普通更新边界保存，world size固定1；并不支持弹性重分片恢复。

公开SmolLM2分支使用原分词器/位置机制，B2/S64、8更新、lr2e-5、CPU4线程。它没有严格优化器续训功能。不得把默认字节ID、位置64和状态文件套到公开模型。

# 中训练教学实验预定方案（2026-10-23，运行前记录）

问题：相同小基座、相同新增目标token预算下，领域数据与通用回放怎样改变两个固定验证集合的NLL？不是寻找生产最优配比。

- 原创虚构设备NX与通用GX模板；各64训练/16验证文档，以实体ID隔离。共用模板/标签，不能据此判断新模板、新主题或真实维修泛化。无外部语料。
- 257字节词表（0–255 UTF-8字节、EOS256），固定可学习位置表64；base只训练长度32。1层、width32、4头、FFN128、dropout0，共享输入输出。
- seed42/43各自训练120更新通用base；batch4、length32、每更新128目标。每个base为一个配对区组，不把验证窗口数当独立重复。
- 三支：通用继续训练（100%通用）、领域独占（0%通用）、25%通用回放；均96更新/12288新增目标，lr0.001。各支只继承同一base权重，AdamW和阶段计数重建。每seed用独立确定性随机数打乱支路执行顺序。
- 固定seed42回放终点另开长度接口对照：S32/B4与S64/B2，各48更新/6144目标；通用目标均1536，领域4608。此语料没有专门远距离依赖，不把长度接口对照称长上下文能力提升。
- 学习率4步warmup后cosine到峰值的10%；base峰值0.003。AdamW decay0.01、裁剪1、FP32、CPU单线程。完整终点预先固定，不挑最好步替代终点。
- 验证：固定窗口索引，通用/领域各16×32=512目标；另各8×64=512。发布各seed逐点NLL、原始生成、实际源消费、窗口身份和环境。只描述观察，不进行小样本显著性或普遍因果宣传。
- 单独严格恢复/拒绝检查、因果可见范围、加权归约和新阶段状态检查。完整语言模型长上下文、RoPE/YaRN、DDP/GPU、生产吞吐均不在默认实验实测范围。

任何实现错误导致重跑时说明原因，正式报告与最终代码绑定；不通过改奖励、删失败样本或挑seed美化结果。

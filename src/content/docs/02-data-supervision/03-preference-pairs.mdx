## 现场问题

一位标注员偏爱简洁，另一位偏爱详细；数据把所有长回答标为chosen，却称其为“更正确”。

## 保持prompt相同，说明比较准则

一条标准成对记录是 `(x,y_w,y_l)`：同一prompt下，chosen优于rejected。示例中 `x=Q:2+3\nA:`，`y_w=5`，`y_l=6`，偏好来自精确答案规则，不是假装收集了人类标注。两回答都应是完整候选，保持相同模板和结束约定。

| 字段 | 例子 | 为什么要保留 |
| --- | --- | --- |
| prompt_id / group_id | add-2-3 / 2+3 | 配对、划分与去重 |
| chosen / rejected | 5 / 6 | 可重算概率与评分 |
| rubric_version | exact-decimal-v1 | 正确、格式、风格不能混称 |
| origin / generator | 人工、模型版本或规则 | 发现来源偏差 |
| annotator / agreement | 多人判断及分歧 | 区分不确定与真实一致 |

分歧并非一定是噪声；两个都正确的回答可能反映不同用户偏好。允许tie、弃权或分层标签，比强制每对选出唯一“好答案”更诚实。要先定义数据协议，再选择能消费它的目标。

## 从比较标签训练一个评分器

数据里只有“选A不选B”，在线采样却会产生新回答。希望把比较经验推广成新回答的分数，就需要一个**奖励模型（Reward model）**：输入问题与完整回答，输出一个可训练标量。它与负责生成下一token的策略承担不同职责。

取同题两回答的模型分数为 `s_w=2、s_l=1`。Bradley–Terry模型把差值映成偏好概率：

$$P(w\succ l\mid x)=\sigma(s_w-s_l),\qquad L_{RM}=-\log\sigma(s_w-s_l).$$

此时预测chosen获选的概率约0.731059，loss约0.313262。对两个分数的梯度约为−0.268941、+0.268941：梯度下降提高chosen分数、降低rejected分数，再通过网络反传更新评分器。真实标注可能有分歧，单对标签不是确定真理。[3，§3.5；1，§3 Eq1–2]

```text
同prompt两回答 + 比较标签
  → 评分器分别打分 → 分差的二分类损失 → 更新奖励模型
新回答 → 冻结的奖励模型打分 → 交给策略优化
```

训练评分器时更新其参数；训练策略时通常冻结评分器，奖励作为策略学习的反馈，并不把离散生成过程直接反传穿过去。给两分同时加10不会改变偏好概率，所以分差拟合**没有确定跨题的绝对分数标尺**。训练集高分也不能当用户满意度百分比。

### 奖励模型自己怎样验收

先按prompt/来源组留出比较集，测排序准确、平局与分歧，再按长度、任务与标注来源分层；若要把概率用于决策，还要看概率校准。对策略更新后产生的新候选重新审阅，检查分布变化后的高分错答。留出排序通过不等于不会奖励作弊，风险接[4.4](/postraining/04-online-rl-distillation/04-reward-engineering/)。

**与DPO的连接**：这条路径先把比较训练成显式评分器，再用评分器优化策略；DPO把同类偏好假设与KL约束下的策略关系代入比较损失，直接更新策略。[3.4](/postraining/03-supervised-preference/04-dpo-objective/)解释为何出现参考概率比。本轮只实际核对这个标量算例，没有训练神经奖励模型。

> 先能讲清“标签训练评分器，评分器再给策略反馈”即可；概率推导可到3.4的折叠区继续。


## 长度与负例的捷径

假设所有chosen都以“当然”开头，所有rejected都很短，模型可以学会前缀和长度，而没有学会正确性。对照同格式近错答案、同长度好坏回答，分层检查margin。真实偏好中长度和质量也可能相关，不能机械删除所有长度差；要看目标和评测控制。

本代码的负例为 `(正确和+1)%19`，是可检查的简单规则，并非难负例挖掘。某些chosen/rejected长度不同，原始DPO使用回答log概率求和而非逐token平均；因此我们同时记录回答NLL和真实生成，不把固定负例排序当通用偏好能力。

## 缓存前先冻结接口

DPO可以提前计算参考logp，但缓存键至少应绑定参考权重、prompt/回答token、模板、EOS和截断。若答案`18`被截成`1`，参考仍对旧文本打分，loss可能有限却含义已错。随机抽十对直接前向与缓存比对，检查相同文本和有效位置，再开大批训练。

> **一句话听懂**：同prompt、同准则、可追溯来源，才能解释一条偏好标签。

> **到这里，你应该已经能听懂：**“先验收奖励模型的留出排序，再独立验收策略的真实输出。”

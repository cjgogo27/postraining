## 先看需求与证据

先读1.1/1.2/1.3，理解示范、偏好、奖励不是同一种标签；再读2.1/2.4/2.5，核对数据覆盖、验收规则和来源。第3/4章可先看表格与“一句话听懂”，遇到关键术语再展开公式。

| 对外表述 | 先问什么 |
| --- | --- |
| “更符合用户偏好” | 谁的偏好、哪些任务、怎样比较 |
| “推理提升” | 是自由生成、固定候选排序还是oracle选择 |
| “更安全” | 不当配合与无害误拒是否分别测量 |
| “便宜/更快” | 是否包含采样、教师/奖励评分和服务预算 |
| “训练稳定可恢复” | 哪种环境、布局和保存边界验证过 |

## 本书最需要保留的反例

SFT300步生成1/23正确，DPO120步为0/23，而固定pair排序从14/23到17/23。它不能被改写成“偏好训练提升数学能力”。有限动作RL的12/12只覆盖训练题四个候选，不是自由生成成绩。

读5.1–5.5与6.5时，始终区分手算、本站实测和引用他人结果。LoRA、OPD、裁判和安全没有本项目成绩；不因为概念讲过就声称已经验证。发现缺项时应补证据，而不是补一个更强的宣传形容词。

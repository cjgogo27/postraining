## 建立机制，再读缩写

建议顺序：[第1章总图](/postraining/01-system-overview/03-posttraining-system-architecture/?reader=student) → [必要基础](/postraining/00-reading-guides/05-essential-foundations/) → 2.2模板/mask → 3.1 SFT → 2.3奖励模型 → 3.4 DPO → 4.1轨迹 → 4.2 PPO → 4.3 GRPO → 4.5蒸馏 → 第5章证据 → 第6章实验。条件概率与梯度不熟时，先在必要基础完成三候选手算。

第一遍只读场景、直觉、图和“到这里应该能听懂”；第二遍打开推导折叠区；实现查阅时再核对ID、形状与分母。每节的角色选择器会记住阅读视角，其余问题保留为折叠项。关闭JavaScript时仍可展开所有问题。

## 最短可运行路线

[1.3](/postraining/01-system-overview/03-posttraining-system-architecture/) → [必要基础](/postraining/00-reading-guides/05-essential-foundations/) → [2.2](/postraining/02-data-supervision/02-template-and-mask/) → **[6.1环境准备](/postraining/06-tools-practice/01-environment-and-artifacts/)** → [6.2 SFT/DPO](/postraining/06-tools-practice/02-offline-sft-dpo/) → [6.4验证](/postraining/06-tools-practice/04-stage-handoff-and-resume/)。之后做6.3有限动作RL，明确它没有语言模型泛化。

## 五个可手算的检查点

1. 画出Q:2+3换行A:与5/EOS的右移标签，找两个有效位置。
2. 算2位置loss2、3位置loss4的总体平均3.2。
3. 用DPO页面计算器核对m=0.2、loss约0.598139。
4. 算奖励[0,0,1,1]的总体标准差和优势。
5. 区分23题上的pair排序与greedy严格正确率。

每节先回答“学生”问题，再展开折叠答案。可以用自己的表述，但单位、条件和因果关系必须一致。记录负结果也有价值，不把示例没有学会加法等同于没有学会检查系统。

## 从机制走到应用

进入RL前增加[RL地图](/postraining/00-reading-guides/06-rl-map/)这一步：把在线/离线与on/off-policy分开，再手算4.2的两步GAE和四区间clip。读完4.3/4.5后运行6.3新增的12项数值检查，逐条对照报告；[附录E](/postraining/07-appendix/e-agentic-multi-agent-rl/)与[10份资料](/postraining/07-appendix/f-rl-reading-list/)按需延伸，不是最短运行路线的前置要求。

算术负责手算；工单助手负责串起示范、偏好与工具轨迹。完成6.2默认路线后，可选已有基座SFT；看固定样本前后对照，再在4.1区分assistant动作和tool观察。读完约需增加一轮30–45分钟概念练习；模型下载与实际运行时间单独预留，不计入阅读时长。

## 先会解释完整的一轮

在4.2前读[RL基础](/postraining/00-reading-guides/07-rl-foundations/)，手算查单成本、回报、V/Q/A；然后按1.3的8轨迹/28位置例子核对更新数，再读5.4。6.4额外生命周期夹具是可选的综合练习，默认仍可只跑单进程；不要跳过6.1环境。

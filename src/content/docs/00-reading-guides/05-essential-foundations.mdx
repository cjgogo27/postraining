## 为什么“给正确答案”能改变下一次回答

先沿一条短链走：**token → 条件概率 → 序列概率 → 交叉熵 → 梯度更新 → 采样与期望**。本页的三候选数值是手算模型，不是本站语言模型的词表或实测。

## 1. token是单位，概率是对下一个单位的判断

token是分词器把文本转换成的编号单位，可能是字节、词片或特殊标记。相同文字换分词器，编号和长度都可能改变。[2.2](/postraining/02-data-supervision/02-template-and-mask/)再看真实字节与右移。

给定问题“2+3”，假设下一个位置只有三个候选 `5、6、其他`。模型先输出三个任意实数分数 **logits**，例如 `ln(0.2)、ln(0.3)、ln(0.5)`；softmax把它们变为和为1的概率 `0.2、0.3、0.5`。给全部logits加同一常数，概率不变；logit本身不是概率。

**条件概率**中的条件是问题与已经生成的前缀。输出了`1`之后，模型面对的是“接在1后面写什么”，而非再次独立回答原问题。

## 2. 一段回答的概率怎样得到

假设在固定前缀下写`5`的概率是0.2，写完`5`后结束的概率是0.5，则完整回答`5 + EOS`的概率为 `0.2×0.5=0.1`。这是链式法则，不需要假设两个位置独立。取自然对数后，乘法变为相加：联合logp为 `ln(0.1)≈−2.302585`。

**交叉熵**衡量模型给示范目标分配的概率有多低。单一正确标签的损失是负log概率；两个目标的NLL和是2.302585，按有效位置平均是1.151293 nats/位置。序列概率、NLL和、位置均值是三个量，不能混写。

## 3. 梯度怎样让概率动起来

仍看三个候选，示范标签为`5`。对单位置交叉熵，logits梯度为 `p−one_hot(5)=[−0.8,0.3,0.5]`。梯度描述损失对参数的小变化有多敏感；**梯度下降沿负梯度更新**，因此正确项的logit会上升。

若只把这三个logits当可训练参数，做学习率0.1的SGD，新logits为旧值加 `[0.08,−0.03,−0.05]`；再softmax后`5`的概率约0.2203。实际Transformer通过链式法则更新共享权重，一次更新还会影响其他题，不能保证每道题都更好。

> 第一次阅读到这里，先能解释“示范把哪些概率往哪个方向推”即可。下面为在线学习准备采样与期望；导数细节可回看[3.1](/postraining/03-supervised-preference/01-sft-tensors-and-loss/)。

## 4. 为什么RL需要采样与期望

假设策略只可能答`5`或`6`，概率分别0.25与0.75，奖励分别1与0。**期望奖励**为 `0.25×1+0.75×0=0.25`。一次恰好答对，不能把期望写成1；重复采样的均值是对期望的估计，有限样本会波动。

真实回答空间无法逐个枚举，RL用采样估计怎样改变分布能提高期望。对已经抽出的离散token编号直接求导无法穿过抽样选择，但可以对“这个动作的log概率”求导。[4.2](/postraining/04-online-rl-distillation/02-ppo-advantage-and-kl/)从这里推到策略梯度与PPO。

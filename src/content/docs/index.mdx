## 这本书回答什么

模型会续写，不等于会按用户目标完成任务。从“2+3，只输出数字”开始，追踪示范、偏好、采样轨迹、奖励、梯度与模型版本，解释SFT、DPO、PPO/GRPO、RLVR和蒸馏怎样连接。

六章29个教学小节、87个角色问答。借鉴参考教程的场景、接口表、总图、反馈与共用支撑，正文和图示围绕后训练重新编写。公式服务于机制与检查，不要求读者先背缩写。

## 每一节怎样读

现场问题 → 选择一个角色问题 → 解释为什么需要 → 图表/手算/可选推导 → 工作用语自检 → 折叠参考答案 → 一手资料。[必要基础](/postraining/00-reading-guides/05-essential-foundations/)连接概率、梯度与采样；1.3是接口地图，工单助手连接真实任务。

<Aside type="note" title="保留真实结果，也保留边界">
  小语言模型从随机权重开始，只检验机制。SFT后生成仍很弱，DPO最终生成回退也原样保留。有限动作RL是48参数表格策略，不是语言模型GRPO。16项CPU数值/恢复检查不代表生产或通用能力验收。
  可选SmolLM2基座SFT已实际运行，固定同模板状态题0/6→6/6；基础续写仍保留问题，不宣称客服泛化或全面能力保留。
</Aside>

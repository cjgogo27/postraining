---
title: 附录A 术语与容易混淆的对象
---

| 术语 | 本书约定 | 常见混淆 |
| --- | --- | --- |
| SFT | 按示范目标学习条件输出 | 等同无掩码文本续写 |
| DPO | 原始回答联合logp差的偏好目标 | chosen绝对概率必然单调上涨 |
| RLHF / RLVR | 人类反馈范式 / 可验证奖励来源 | 当成与PPO同层的算法名 |
| PPO / GRPO | 受限策略更新 / 组相对优势路径 | 所有实现的归约与KL都相同 |
| policy / old / ref | 当前更新 / 行为采样 / 漂移基准 | 因为初始相同就共用可变身份 |
| critic | 估计回报基线 | 以为所有RL都必须有 |
| reward / advantage | 评分 / 相对基准信号 | 把1分直接称作所有token优势 |
| ORM / PRM | 结果 / 过程监督 | 以为过程分数自动可靠 |
| response mask | 哪些目标计loss | 当成注意力可见范围 |
| rollout | 带身份、概率、结束原因的采样经历 | 只剩一段文本 |
| on-policy | 采样分布与当前更新相关的约定 | 不记录版本便声称完全新鲜 |
| OPD | 学生轨迹上的教师蒸馏路径 | 教师文本SFT直接改名OPD |
| KL | 指定方向/分布的散度 | 单个采样log比必须非负 |
| step / iteration | optimizer更新 / rollout轮 | 两个都叫训练步却不说明 |
| pair accuracy | 固定候选的排序正确率 | 实际自由生成准确率 |
| init / resume | 新阶段继承权重 / 同运行完整恢复 | 只要load权重就叫严格恢复 |

| 新增连接词 | 本书约定 | 去哪里查 |
| --- | --- | --- |
| logits / 条件概率 | softmax前分数 / 固定前缀下的下一token分布 | 必要基础、3.1 |
| 序列logp / 平均NLL | 条件logp之和 / 有效监督位置的负logp均值 | 必要基础、2.2 |
| 策略梯度 / 基线 | 用采样奖励加权log概率梯度 / 不依赖当前动作的比较基准 | 4.2 |
| RM偏好损失 | 评分差经sigmoid预测比较标签 | 2.3 |
| 动作 / 观察 | assistant作出的选择 / 用户或工具提供的环境信息 | 4.1 |
| 保留能力探针 | 固定的少量旧行为观察，不等于全面回归基准 | 6.2 |

这些是本书接口约定；术语在其他框架有不同用法时，以实际张量、采样和目标为准。缩写不是完整配方。
